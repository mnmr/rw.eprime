---
title: Ebenen im Gruppeneditor
---
Der Gruppeneditor zeigt ein Band pro Ebene mit denselben Symbolen und Anzahlen wie die Ressourcenanzeige:

![Die Nahrungsgruppe im Gruppeneditor](group-tiers.png)

Eine Gruppe beginnt mit einer Ebene. Sobald diese etwas enthält, erscheint darunter eine leere Ebene. Jede Ebene fasst bis zu acht Felder; eine Ressource darf pro Gruppe nur einmal vorkommen.

- Klicke auf eine Ressource im Ressourcenpanel, um sie an die letzte Ebene anzufügen, oder an eine neue, wenn die letzte voll ist.
- Ziehe eine Ressource aus dem Ressourcenpanel auf ein Feld, um sie dort abzulegen.
- Ziehe ein Feld innerhalb einer Ebene oder zu einer anderen.
- Rechtsklick entfernt das Feld aus der Gruppe. Leere Ebenen verschwinden; darunterliegende rücken nach oben.
- Klicke auf ein Feld, um seine Optionen zu öffnen (siehe [Feldoptionen](topic:slot-options)).

Die Ebenen gehören zum Spielstand. Alle Spieler einer Mehrspielerpartie sehen dieselben Gruppen.

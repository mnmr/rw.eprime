---
title: New-game defaults
---
<!-- l10n:b-1a49731415ce -->
Set defaults, at the top of the editor, lets you save this colony's setup as your personal starting point. Click Use this setup for new games to save it.

<!-- l10n:b-ae776ebe74e1 -->
![Saving a personal setup with automatic updates enabled](default-settings.png)

<!-- l10n:b-f058c22a3669 -->
Future colonies receive its groups, pools, thresholds, count overrides and enabled groups. Your current global display and counting options stay in use. Existing colonies keep their own setups.

<!-- l10n:b-3649c3e16bdf -->
Current tier depth, search text, scroll positions and temporary editor state are excluded. If a mod is missing, its entries are skipped in the new colony but kept in your personal default, ready for when that content returns.

<!-- l10n:b-351f8d1302e2 -->
## Keep the default up to date

<!-- l10n:b-db32eb022fca -->
Automatically update after configuration edits is optional. Turn it on before saving to keep your personal default in step with later configuration changes. Updates are saved when you close the editor or leave the game. Showing more or fewer tiers in the readout does not update the default.

<!-- l10n:b-98f276ec5465 -->
With automatic updates on, a loaded colony may have a different setup from your saved default. The first time you open the editor in that session, Readouts asks what to do:

<!-- l10n:b-f01946f24921 -->
![The choices when a colony differs from the personal default](default-conflict.png)

<!-- l10n:b-e2a67ef08adb -->
- Use this setup for new games replaces your default with this colony's setup and keeps automatic updates on.
- Keep my default for this session leaves the saved default unchanged while you edit this colony during the session.
- Turn off auto-update keeps your saved default and disables automatic updates.

<!-- l10n:b-4de66c8294ae -->
Loading a colony alone does not change your default or show this prompt. None of these choices replaces the current colony's setup.

<!-- l10n:b-8c706950b6af -->
## Return to the built-in setup

<!-- l10n:b-95d613194d3c -->
Open Set defaults and choose Use built-in defaults for new games to remove your personal default and turn off automatic updates. Future colonies then start with the setup shipped with Readouts.

<!-- l10n:b-cbb28ffd4edb -->
To reset the current colony instead, use Restore defaults (see [Sharing groups](topic:sharing-groups)).

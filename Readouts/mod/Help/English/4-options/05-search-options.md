---
title: Search options
---
Show search filter puts the search field in the panel header:

![The header with the search field](header-search.png)

Turn it off for a plain header; any search that was active is cleared at the same time. Show mod name appears once the field is hidden, and decides whether the header shows the mod name or nothing at all:

![The header with the mod name instead](header-modname.png)

Hide zero-count results drops resources with a count of zero from the search results. While Only count items in storage is on, resources with nothing in storage never appear in the results, whatever this option says (see [Count options](topic:count-options)).

<!-- l10n:intro -->
This chapter has one page per mod that Readouts was checked against.

<!-- l10n:verdicts -->
| ![Fully compatible](verdict-green.png|16) **Fully compatible** | Works out of the box; no custom code required. |
| ![Fully compatible](verdict-blue.png|16) **Fully compatible** | Works because Readouts added custom support for the mod. |
| ![Partially compatible](verdict-yellow.png|16) **Partially compatible** | The mods can coexist, but not every feature works or is supported. |
| ![Incompatible](verdict-red.png|16) **Incompatible** | Does not work. |

<!-- l10n:requirements -->
Readouts requires Harmony and runs on RimWorld 1.6 and 1.7. No DLC is
required. It can be added to or removed from a save at any time; removing a
content mod cleans its resources out of your groups on the next load.

<!-- l10n:welcome-notice -->
When an incompatible mod is active, the welcome dialog that opens the first
time you load a save names it and says what clashes. The dialog shows once
per save and opens once more only when a new conflicting mod appears.

<!-- l10n:multiplayer -->
In Multiplayer, group definitions, pools and thresholds are shared and kept
in sync between players. Which tiers each player has open, the toolbar toggle
and the help topics you have read stay personal.

<!-- l10n:report -->
Found a mod that misbehaves next to Readouts? Say so in the Workshop
comments, naming the mod and what you saw, so it can get a page here.

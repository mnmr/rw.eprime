<!-- l10n:summary -->
Floors of one level stack count as one colony.

<!-- l10n:counts -->
Every readout counter adds up the resources on all floors of the stack you
are looking at, and every floor shows the same numbers. Thresholds, planned
work and resource pools use the same stack totals.

<!-- l10n:limits -->
Readouts reads MultiFloors' level list through that mod's own code. If a
MultiFloors update changes it, Readouts logs one warning and falls back to
counting each floor on its own until it is updated.

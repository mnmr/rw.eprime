<!-- l10n:summary -->
Strata's combined resources setting decides what a counter covers.

<!-- l10n:combined -->
With Strata's combined resources setting on, Readouts adds up every level you
can reach from the one on screen, and every level shows the same totals. The
stored, forbidden and scattered breakdown in a slot's tooltip and the planned
work deductions follow the same levels, so they match the counter.

<!-- l10n:per-level -->
With the setting off, each level shows only what is on that level.

<!-- l10n:limits -->
Readouts reads Strata's level graph through that mod's own code. If a Strata
update changes it, Readouts logs one warning and uses the game's own resource
counters until it is updated.

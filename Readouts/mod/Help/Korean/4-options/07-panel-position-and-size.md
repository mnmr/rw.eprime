## 위치와 크기

<!-- l10n:b-15c2f6d16365 -->
위치 및 크기 옵션 아래의 슬라이더로 패널을 조정합니다.

<!-- l10n:b-b666a5f1345e -->
![패널 위치와 크기 슬라이더](position-size.png)

<!-- l10n:b-67c2c540ddd4 -->
- 가로 위치 조정과 세로 위치 조정은 패널을 모서리에서 0~200픽셀 옮깁니다. 기본값은 각각 7입니다.
- 패널 너비는 머리글과 검색 결과의 너비를 80~400픽셀로 설정하며 기본값은 140입니다. 넓은 띠는 이 너비를 넘어 펼쳐집니다. 패널을 넓히면 검색 결과가 최대 여섯 열까지 들어갑니다.
- 아래 여백은 패널과 화면 아래쪽 사이에 공간을 확보합니다. 범위는 0~500픽셀이며 기본값은 200입니다. 이 경계를 넘어가는 패널은 마우스 휠로 스크롤합니다.

<!-- l10n:b-7b42232657ab -->
변경 사항은 즉시 표시됩니다. 위치와 크기 초기화는 다른 옵션을 바꾸지 않고 이 네 가지 값을 기본값으로 되돌립니다.

<!-- l10n:b-27b9e8c99811 -->
## 게임의 기본 자원 표시 사용

<!-- l10n:b-48ae8ebe7450 -->
표시 옵션 맨 아래의 기본 자원 표시 사용은 확인을 거친 뒤 게임의 기본 자원 표시와 범주별 표시 전환 버튼으로 전환합니다. Readouts는 설치된 상태로 두어도 됩니다.

<!-- l10n:b-a1b50e1767fc -->
설정 창을 닫은 뒤 Readouts를 다시 사용하려면 옵션 → 모드 설정 → EPrime's Readouts를 열고 기본 자원 표시 사용을 끄세요.

---
title: Editar um conjunto
---
Use o botão superior para mudar o painel central para o Editor de conjuntos de recursos:

![Alternância entre os dois editores](editor-mode.png)

Clique em Adicionar abaixo e digite um nome para criar um conjunto. Selecione-o na lista para editar. Os dois botões de cada linha renomeiam ou excluem.

Com um conjunto selecionado, Recursos mostra caixas diante das categorias e recursos:

![Integrantes de Refeições no painel Recursos](pool-members.png)

Marque uma categoria para incluir tudo nela ou marque recursos individuais. Uma categoria parcialmente incluída tem uma marca parcial; clicar no nome a abre ou fecha. A caixa de categoria só afeta os recursos listados naquele momento, portanto os filtros ativos de busca, objetos e origem limitam o que será adicionado ou removido.

Clique no ícone de qualquer recurso para usá-lo no conjunto. O nome escolhido fica amarelo; o ícone automático do primeiro membro não recebe marca.

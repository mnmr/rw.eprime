---
title: A lista de grupos
---
Grupos lista todos os grupos na ordem do painel:

![O painel Grupos](groups-panel.png)

- Clique no nome para abrir o grupo no editor.
- Clique na marca para mostrar ou ocultar o grupo. Isso só altera sua visualização; outros jogadores mantêm as próprias.
- Clique no X para excluir, após confirmar.
- Arraste um nome para cima ou para baixo para reorganizar as faixas.
- Digite um nome no campo inferior e clique em Adicionar. O grupo novo abre no editor e fica visível para você.

O nome e o botão de renomear ficam acima dos níveis no Editor de grupos.

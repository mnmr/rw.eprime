---
title: Valores predeterminados para nuevas partidas
---
<!-- l10n:b-1a49731415ce -->
Establecer valores predeterminados, en la parte superior del editor, permite guardar la configuración de esta colonia como tu punto de partida personal. Haz clic en Usar esta configuración para nuevas partidas para guardarla.

<!-- l10n:b-ae776ebe74e1 -->
![Guardar una configuración personal con las actualizaciones automáticas activadas](default-settings.png)

<!-- l10n:b-f058c22a3669 -->
Las futuras colonias reciben sus grupos, conjuntos, umbrales, excepciones de recuento y grupos activados. Se siguen usando tus opciones globales actuales de visualización y recuento. Las colonias existentes conservan sus propias configuraciones.

<!-- l10n:b-3649c3e16bdf -->
Se excluyen el número actual de niveles visibles, el texto de búsqueda, las posiciones de desplazamiento y el estado temporal del editor. Si falta un mod, sus entradas se omiten en la nueva colonia, pero se conservan en tu configuración predeterminada personal para cuando ese contenido vuelva a estar disponible.

<!-- l10n:b-351f8d1302e2 -->
## Mantener actualizada la configuración predeterminada

<!-- l10n:b-db32eb022fca -->
Actualizar automáticamente al editar la configuración es opcional. Activa esta opción antes de guardar para mantener tu configuración predeterminada personal al día con los cambios posteriores. Las actualizaciones se guardan al cerrar el editor o salir del juego. Mostrar más o menos niveles en el panel no actualiza la configuración predeterminada.

<!-- l10n:b-98f276ec5465 -->
Con las actualizaciones automáticas activadas, una colonia cargada puede tener una configuración distinta de tu configuración predeterminada guardada. La primera vez que abras el editor durante esa sesión, Readouts te preguntará qué hacer:

<!-- l10n:b-f01946f24921 -->
![Las opciones cuando una colonia difiere de la configuración predeterminada personal](default-conflict.png)

<!-- l10n:b-e2a67ef08adb -->
- Usar esta configuración para nuevas partidas reemplaza tu configuración predeterminada por la de esta colonia y mantiene activadas las actualizaciones automáticas.
- Conservar mi configuración predeterminada durante esta sesión deja intacta la configuración predeterminada guardada mientras editas esta colonia durante la sesión.
- Desactivar la actualización automática conserva tu configuración predeterminada guardada y desactiva las actualizaciones automáticas.

<!-- l10n:b-4de66c8294ae -->
Cargar una colonia por sí solo no cambia tu configuración predeterminada ni muestra esta pregunta. Ninguna de estas opciones reemplaza la configuración de la colonia actual.

<!-- l10n:b-8c706950b6af -->
## Volver a la configuración incluida

<!-- l10n:b-95d613194d3c -->
Abre Establecer valores predeterminados y elige Usar valores predeterminados del mod para nuevas partidas para eliminar tu configuración predeterminada personal y desactivar las actualizaciones automáticas. Las futuras colonias comenzarán con la configuración incluida con Readouts.

<!-- l10n:b-cbb28ffd4edb -->
Para restablecer la colonia actual, usa Restaurar valores predeterminados (consulta [Compartir grupos](topic:sharing-groups)).

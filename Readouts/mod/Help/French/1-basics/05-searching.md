---
title: Recherche
---
Tapez dans le champ en haut du panneau pour trouver une ressource, qu'elle figure ou non dans un groupe :

![Résultats de recherche pour un repas](search-results.png)

Les ressources correspondantes apparaissent dans une section Résultats au-dessus des groupes, sur trois lignes au maximum, avec une ligne indiquant combien restent. Les ressources non nulles viennent d'abord, par ordre alphabétique ; celles à zéro suivent si les options les autorisent. Les cases correspondantes de vos groupes sont aussi surlignées ; une case d'ensemble correspond selon son nom. Cliquez sur le X voisin ou appuyez sur Échap pendant la saisie pour effacer la recherche.

Les options de recherche permettent de masquer les résultats à zéro ou de retirer le champ de l'en-tête (voir [Options de recherche](topic:search-options)). Les quantités suivent les réglages de l'onglet Options (voir [Options de comptage](topic:count-options)).

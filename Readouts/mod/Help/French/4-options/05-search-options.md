---
title: Options de recherche
---
Afficher le filtre de recherche place le champ dans l'en-tête :

![En-tête avec champ de recherche](header-search.png)

Désactivez-le pour un en-tête simple ; toute recherche active est alors effacée. Afficher le nom du mod apparaît une fois le champ masqué, et détermine si l'en-tête montre ce nom ou reste vide :

![En-tête affichant le nom du mod](header-modname.png)

Masquer les résultats à zéro retire les ressources de quantité nulle des résultats. Lorsque Compter uniquement les objets stockés est activé, les ressources sans stock n'apparaissent jamais dans les résultats, quel que soit ce réglage (voir [Options de comptage](topic:count-options)).

---
title: Options de comptage
---
<!-- l10n:b-6f3571147ee2 -->
Les options de comptage choisissent quelles piles entrent dans tous les compteurs du panneau. Elles sont toutes deux activées à l'installation.

<!-- l10n:b-4b05bbeaf027 -->
Compter uniquement les objets stockés compte les piles dans les zones ou bâtiments de stockage, comme les étagères. Les objets posés ailleurs sur la carte sont exclus :

<!-- l10n:b-56868d79ec0a -->
![Aliments crus avec comptage limité au stockage](storage-only-on.png)

<!-- l10n:b-5257c4ea48ab -->
Désactivée, cette option permet de compter les objets partout sur la carte :

<!-- l10n:b-c776b2fe96b1 -->
![Mêmes cases sans limitation au stockage](storage-only-off.png)

<!-- l10n:b-458375c38d68 -->
Ignorer les objets interdits exclut les piles interdites.

<!-- l10n:b-494a65d183c5 -->
Certains objets ne sont jamais comptés : objets pourris, cachés dans les zones inexplorées, portés par un colon ou placés dans un inventaire ou un conteneur.

<!-- l10n:b-47646bfea73a -->
Comme les objets portés ne comptent pas, un compteur baisse normalement dès qu'un colon ramasse une pile. Les matériaux de construction font exception. Si Réserver les ressources des constructions est activé (voir [Travaux prévus](topic:planned-work)), les besoins du plan ont déjà été déduits lors de sa pose : ramasser et livrer ces matériaux ne les déduit pas une deuxième fois.

<!-- l10n:b-832cdb341680 -->
Le panneau actualise les quantités toutes les quelques secondes de temps de jeu. Modifier une option de comptage les actualise immédiatement, même en pause. Une ressource ou un ensemble peut remplacer les deux options pour toutes ses cases (voir [Options des cases](topic:slot-options)).

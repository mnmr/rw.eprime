---
title: Valeurs par défaut des nouvelles parties
---
<!-- l10n:b-1a49731415ce -->
Définir les valeurs par défaut, en haut de l'éditeur, permet d'enregistrer la configuration de cette colonie comme point de départ personnel. Cliquez sur Utiliser cette configuration pour les nouvelles parties pour l'enregistrer.

<!-- l10n:b-ae776ebe74e1 -->
![Enregistrement d'une configuration personnelle avec les mises à jour automatiques activées](default-settings.png)

<!-- l10n:b-f058c22a3669 -->
Les futures colonies reçoivent ses groupes, ensembles, seuils, règles de comptage personnalisées et groupes activés. Vos options globales actuelles d'affichage et de comptage restent en vigueur. Les colonies existantes conservent leur propre configuration.

<!-- l10n:b-3649c3e16bdf -->
Le nombre de niveaux affichés, le texte de recherche, les positions de défilement et l'état temporaire de l'éditeur sont exclus. Si un mod est absent, ses entrées sont ignorées dans la nouvelle colonie, mais conservées dans votre configuration personnelle par défaut, prêtes pour le retour de ce contenu.

<!-- l10n:b-351f8d1302e2 -->
## Maintenir la configuration par défaut à jour

<!-- l10n:b-db32eb022fca -->
L'option Mettre à jour automatiquement après modification de la configuration est facultative. Activez-la avant d'enregistrer pour que votre configuration personnelle par défaut suive les modifications ultérieures. Les mises à jour sont enregistrées lorsque vous fermez l'éditeur ou quittez la partie. Afficher plus ou moins de niveaux dans le panneau ne modifie pas la configuration par défaut.

<!-- l10n:b-98f276ec5465 -->
Lorsque les mises à jour automatiques sont activées, une colonie chargée peut avoir une configuration différente de celle enregistrée par défaut. À la première ouverture de l'éditeur pendant cette session, Readouts vous demande quoi faire :

<!-- l10n:b-f01946f24921 -->
![Choix proposés lorsque la configuration d'une colonie diffère de la configuration personnelle par défaut](default-conflict.png)

<!-- l10n:b-e2a67ef08adb -->
- Utiliser cette configuration pour les nouvelles parties remplace votre configuration par défaut par celle de cette colonie et maintient les mises à jour automatiques activées.
- Conserver ma configuration par défaut pour cette session laisse la configuration enregistrée par défaut inchangée pendant que vous modifiez cette colonie au cours de la session.
- Désactiver la mise à jour automatique conserve votre configuration enregistrée par défaut et désactive les mises à jour automatiques.

<!-- l10n:b-4de66c8294ae -->
Le simple chargement d'une colonie ne modifie pas votre configuration par défaut et n'affiche pas cette demande. Aucun de ces choix ne remplace la configuration de la colonie actuelle.

<!-- l10n:b-8c706950b6af -->
## Revenir à la configuration intégrée

<!-- l10n:b-95d613194d3c -->
Ouvrez Définir les valeurs par défaut et choisissez Utiliser les valeurs intégrées pour les nouvelles parties pour supprimer votre configuration personnelle par défaut et désactiver les mises à jour automatiques. Les futures colonies démarrent alors avec la configuration fournie avec Readouts.

<!-- l10n:b-cbb28ffd4edb -->
Pour réinitialiser la colonie actuelle, utilisez Rétablir les valeurs par défaut (voir [Partager des groupes](topic:sharing-groups)).

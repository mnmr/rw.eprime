---
title: Liste des groupes
---
Le panneau Groupes liste les groupes dans l'ordre d'affichage :

![Panneau Groupes](groups-panel.png)

- Cliquez sur un nom pour ouvrir le groupe dans l'éditeur.
- Cliquez sur la coche pour afficher ou masquer le groupe. Ce choix est personnel ; les autres joueurs gardent le leur en multijoueur.
- Cliquez sur X pour supprimer le groupe, après confirmation.
- Faites glisser un nom vers le haut ou le bas pour réordonner les bandes.
- Tapez un nom dans le champ du bas et cliquez sur Ajouter pour créer un groupe. Il s'ouvre dans l'éditeur et est activé pour vous.

Le nom du groupe et un bouton de renommage se trouvent au-dessus des niveaux dans l'Éditeur de groupes.

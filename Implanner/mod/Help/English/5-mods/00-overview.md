<!-- l10n:intro -->
This chapter explains how Implanner reads implants from any mod, lists the
mod compatibility options, and then has one page per mod that Implanner was
checked against.

<!-- l10n:verdicts -->
| ![Fully compatible](verdict-green.png|16) **Fully compatible** | Works out of the box; no custom code required. |
| ![Fully compatible](verdict-blue.png|16) **Fully compatible** | Works because Implanner added custom support for the mod. |
| ![Partially compatible](verdict-yellow.png|16) **Partially compatible** | The mods can coexist, but not every feature works or is supported. |
| ![Incompatible](verdict-red.png|16) **Incompatible** | Does not work. |

<!-- l10n:any-mod -->
Every implant mod that uses the game's surgery data works without a page
here; see [How modded implants are read](topic:how-modded-implants-are-read).
The pages below cover the mods that needed code of their own or were checked
one by one.

<!-- l10n:requirements -->
Implanner requires Harmony and runs on RimWorld 1.6 and 1.7. No DLC is
required.

<!-- l10n:welcome-notice -->
When a partially compatible mod is active, the welcome dialog that opens the
first time you load a save names it and says what to expect. The dialog
shows once per save and opens once more only when a new such mod appears.

<!-- l10n:multiplayer -->
Plans, assignments, rankings and automation settings are shared by everyone
in a Multiplayer game. Which help topics you have read and the skill slider
range stay personal.

<!-- l10n:report -->
Found a mod that misbehaves next to Implanner? Say so in the Workshop
comments, naming the mod and what you saw, so it can get a page here.

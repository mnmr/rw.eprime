<!-- l10n:summary -->
도구 모음 버튼이 스타일이 바뀐 바 안에 표시됩니다.

<!-- l10n:detail -->
Implanner는 게임 자체의 행 컨트롤로 도구 모음 버튼을 그리므로, 바 스타일을 바꾸는 모드도 기본 게임의 토글처럼 이 버튼을 레이아웃에 배치합니다. 이전 버전은 버튼을 직접 그려서 스타일이 바뀐 바 뒤로 사라졌습니다.

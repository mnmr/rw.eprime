---
title: 자동화 중단
---
<!-- l10n:b-a8ac20c632db -->
탭 위쪽 **자동화 사용**은 전체 자동화 스위치입니다. 끄면 Implanner는 계획 도구로만 작동합니다. 계획·진행도·등급은 유지하지만 Implanner는 물품 예약과 제작·수술 계획서 생성을 중단합니다. 기존 계획서 중 유지하기로 선택한 것은 계속 활성 상태로 남습니다.

<!-- l10n:b-22363c7318de -->
![자동화 전체 스위치](automation-enable.png)

<!-- l10n:b-094c02cc109b -->
끄면 자동화가 이미 만든 계획서를 어떻게 처리할지 먼저 묻습니다. 선택한 계획서는 제거합니다. 선택하지 않은 계획서는 활성 상태로 남아 정착민이 계속 제작하거나 해당 수술을 할 수 있습니다. 자동화를 다시 켜면 Implanner가 남은 계획서 관리를 재개합니다. 예약 물품은 어느 경우든 해제하며, 취소하면 자동화를 유지합니다.

<!-- l10n:b-6747bf547c20 -->
Strata, MultiFloors, As above So below 같은 다층 정착지 모드가 있으면 자동으로 중단합니다. 기본 수술은 층을 넘어 이식물을 가져오지 못하므로 완료 불가능한 수술을 지정하지 않고 예약을 해제합니다. 이미 만든 계획서는 남아 있으니 직접 유지하거나 취소하세요. 나머지 기능은 작동하며 수동 설치도 진행도에 반영됩니다.

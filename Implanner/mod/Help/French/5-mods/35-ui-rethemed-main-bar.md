<!-- l10n:summary -->
Le bouton de la barre d'outils apparaît dans la barre restylisée.

<!-- l10n:detail -->
Implanner dessine son bouton de barre d'outils via les contrôles de rangée du jeu, de sorte que les mods qui restylisent la barre le placent dans leur disposition comme les boutons du jeu de base. Les versions précédentes le dessinaient à la main et le perdaient derrière la barre restylisée.

<!-- l10n:summary -->
A mech in smart work mode qualifies as a finisher.

<!-- l10n:detail -->
Mechs qualify in any work mode that actually runs work, so Smart Work
Mode's smart work keeps a mech available. Escort, combat, recharge and
self-shutdown modes make a mech unavailable.

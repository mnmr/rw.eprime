<!-- l10n:intro -->
This chapter has one page per mod that Quality Jobs was checked against.

<!-- l10n:verdicts -->
| ![Fully compatible](verdict-green.png|16) **Fully compatible** | Works out of the box; no custom code required. |
| ![Fully compatible](verdict-blue.png|16) **Fully compatible** | Works because Quality Jobs added custom support for the mod. |
| ![Partially compatible](verdict-yellow.png|16) **Partially compatible** | The mods can coexist, but not every feature works or is supported. |
| ![Incompatible](verdict-red.png|16) **Incompatible** | Does not work. |

<!-- l10n:requirements -->
Quality Jobs requires Harmony and supports RimWorld 1.6 and 1.7. No DLC is
required. Ideology adds the production-specialist requirement; ordinary
quality management works without it. Biotech mechs that can perform the
required work qualify as finishers like the robots on the
[Misc. Robots](topic:misc-robots) page.

<!-- l10n:welcome-notice -->
When an incompatible mod is active, the welcome dialog that opens the first
time you load a save names it and says what clashes. The dialog shows once
per save and opens once more only when a new conflicting mod appears.
Turning off unfinished-work sharing does not remove every conflict.

<!-- l10n:multiplayer -->
Colony settings and quality-work commands are synchronized in Multiplayer.
Toolbar visibility and which help topics you have read are personal
preferences.

<!-- l10n:report -->
Found a mod that misbehaves next to Quality Jobs? Say so in the Workshop
comments, naming the mod and what you saw, so it can get a page here.

<!-- l10n:summary -->
Les tâches de finition n'apparaissent pas dans ses catégories.

<!-- l10n:detail -->
Personal Work Categories recense les tâches avant que Quality Jobs n'enregistre ses tâches de finition : elles ne peuvent donc pas être placées dans une catégorie propre. Le finisseur effectue quand même le travail avec une priorité élevée grâce à l'option correspondante de Quality Jobs ; seul le placement dans la grille de ce mod fait défaut.

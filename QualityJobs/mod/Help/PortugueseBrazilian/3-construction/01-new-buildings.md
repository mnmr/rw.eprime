---
title: Novas construções
---
<!-- l10n:enable -->
Selecione o projeto ou a estrutura de uma construção com qualidade, como uma cama ou cadeira. **Clique com o botão esquerdo em Trabalho de qualidade** para ativar ou desativar o gerenciamento usando suas configurações padrão de construção. **Clique com o botão direito** para escolher os requisitos de quem finalizará a construção e a qualidade desejada.

<!-- l10n:construction-image -->
![Controles de Quality Job para uma nova construção](construction.png)

<!-- l10n:settings -->
Alterar uma configuração neste painel ativa o gerenciamento. **{k:QJ_Clear}** remove o gerenciamento e permite que a construção seja concluída normalmente. Selecione vários projetos ou estruturas compatíveis para aplicar uma alteração a todos eles.

<!-- l10n:finish -->
Construções gerenciadas exibem um efeito de brilho. Os construtores podem fazer o trabalho inicial, mas a estrutura aguarda na etapa final até que um construtor que atenda aos requisitos possa concluí-la. Se o construtor atual já atender aos requisitos, a construção é concluída sem passar o trabalho para outro.

<!-- l10n:copy -->
O comando normal **Construir cópia** transfere as configurações de Quality Jobs de um projeto ou estrutura gerenciado para os novos projetos. Para gerenciar automaticamente todas as novas construções com qualidade, ative **{k:QJ_SettingsManageNewConstruction}** nas Opções.

<!-- l10n:retry-link -->
Deixe **{k:QJ_MinQualityLabel}** em **{k:QJ_NoRetries}** para aceitar o primeiro resultado. Escolha uma qualidade para [reconstruir resultados abaixo da qualidade desejada](topic:retries).

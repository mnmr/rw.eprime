Allow Tool 的工作会自动归入匹配的预设角色。

<!-- l10n:detail -->
Haul+ 会加入“基础”角色,其他工作则加入已涵盖其工作内容的角色。像“补刀”这样的一次性工作不会让“基础”或“猎人”被视为近战角色。在已使用 Allow Tool 的存档中加入 WorkRoles 后,原本拥有 Haul+ 的殖民者仍会保留它。

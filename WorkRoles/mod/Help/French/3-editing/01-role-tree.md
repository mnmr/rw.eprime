---
title: Arbre des rôles
---
<!-- l10n:b-dcdcbd6851f0 -->
La partie gauche de l'onglet Rôles liste tous les rôles de la colonie. La plupart se trouvent dans vos groupes nommés, comme celui-ci :

<!-- l10n:b-f3de2894b112 -->
![Groupe Intérieur avec rôles imbriqués](role-tree.png)

<!-- l10n:b-e37055522a90 -->
Les groupes n'ont pas besoin d'écran d'édition : attribuez un nouveau nom de groupe à un rôle pour le créer ; déplacez son dernier rôle ailleurs pour le faire disparaître. Faites glisser les rôles pour les réordonner dans un groupe ou les déplacer entre groupes ; cliquez sur un rôle pour ouvrir son [éditeur](topic:role-editor).

<!-- l10n:b-e0923ff4faea -->
L'indentation est automatique : un rôle couvrant toutes les tâches d'un autre l'affiche sous lui. Bricoleur apparaît ainsi sous Constructeur, puis Réparer les toits sous Bricoleur. Un rôle couvert peut apparaître sous plusieurs parents ; ce sont des occurrences supplémentaires du même rôle, dont le propre groupe reste le véritable emplacement.

<!-- l10n:b-157edb413d02 -->

Les [rôles conditionnels](topic:conditional-roles) s'y regroupent automatiquement et retrouvent leur groupe enregistré lorsque leurs règles sont supprimées.

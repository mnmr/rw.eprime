<!-- l10n:summary -->
Les tâches d'Allow Tool s'intègrent d'elles-mêmes dans les rôles prédéfinis correspondants.

<!-- l10n:detail -->
Haul+ rejoint Base et les autres tâches rejoignent les rôles qui couvrent déjà leur travail. Les tâches ponctuelles comme Achever ne font pas de Base ou de Chasseur des rôles de mêlée. Ajouter WorkRoles à une sauvegarde qui utilise déjà Allow Tool conserve Haul+ attribué aux colons qui l'avaient.

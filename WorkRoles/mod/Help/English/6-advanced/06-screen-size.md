---
title: Screen size
---
<!-- l10n:b-651879e3a79e -->
WorkRoles is designed for a game screen of at least 1536x864. The game
screen is your resolution divided by the UI scale, so 1920x1080 at UI
scale 1.25 matches it exactly.

<!-- l10n:b-692cb76b843c -->
A smaller screen still works: the window fills the screen, some labels
are shortened and the tabs need more scrolling. Lowering the UI scale in
the game's options gives the window more room.

<!-- l10n:b-a3008c0661b3 -->
The selected-colonist panel uses two columns for the usual twelve skills.
Mods that add skills get a third column with a narrower recommendations
panel. More than eighteen skills add extra rows.

<!-- l10n:b-b8fe79d4de1f -->
When the recommended roles do not all fit, scroll inside their panel to
see the rest. The Make It So button stays in view.

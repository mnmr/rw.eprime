## Grouping

Group by splits the table into collapsible sections, here by gender:

![The table grouped by gender](grouped-table.png)

Grouping only arranges rows; the filters still decide who is listed, and
with Colony Groups installed its pawn groups appear as an option.

## Skill columns

The Skills button adds up to three skill columns to the table:

![A skill column with sorted values](skill-column.png)

Click a column header to sort the table by that skill, click its X to
remove the column. Values carry the same passion flames and suitability
colors as the colonist panel.

## Options tab

More display switches live on the Options tab:

![Display settings on the Options tab](options-display.png)

All of these are personal preferences: in multiplayer each player keeps
their own, and nothing here changes any assignment.

<!-- l10n:intro -->
This chapter has one page per mod that WorkRoles was checked against.

<!-- l10n:verdicts -->
| ![Fully compatible](verdict-green.png|16) **Fully compatible** | Works out of the box; no custom code required. |
| ![Fully compatible](verdict-blue.png|16) **Fully compatible** | Works because WorkRoles added custom support for the mod. |
| ![Partially compatible](verdict-yellow.png|16) **Partially compatible** | The mods can coexist, but not every feature works or is supported. |
| ![Incompatible](verdict-red.png|16) **Incompatible** | Does not work. |

<!-- l10n:requirements -->
WorkRoles requires Harmony and runs on RimWorld 1.6 and 1.7. No DLC is
required: Biotech adds mechs to the colonist table when robot and mech
support is on, and Ideology adds the precept signals recommendations read.

<!-- l10n:any-mod -->
Work and jobs from any mod are picked up without a page here; see
[Jobs from other mods](topic:modded-jobs). Mods that only read priorities
see the values WorkRoles computed. Some mods require priorities in the range
0 to 4, so if you have issues with another mod make sure the "Report vanilla
0-4 priorities to other mods" option is enabled.

<!-- l10n:welcome-notice -->
When an incompatible mod is active, the welcome dialog that opens the first
time you load a save names it and says what clashes. The dialog shows once
per save and opens once more only when a new conflicting mod appears.

<!-- l10n:multiplayer -->
WorkRoles is fully Multiplayer compatible; see [Multiplayer](topic:multiplayer).

<!-- l10n:report -->
Found a mod that misbehaves next to WorkRoles? Say so in the Workshop
comments, naming the mod and what you saw, so it can get a page here.

---
title: Make It So
---
The ![Make It So button](make-it-so-btn.png) button under the
Recommended Roles list applies the whole displayed set to the selected
colonist in one click.

Roles the engine did not recommend are removed (except
[pinned](topic:pinning) ones), the rest land in the recommended order.
Handy when one colonist's row has drifted.

For the colony-wide version with a preview, see
[Fix My Colony](topic:fix-my-colony).

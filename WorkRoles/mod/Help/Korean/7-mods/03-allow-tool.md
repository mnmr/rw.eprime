<!-- l10n:summary -->
Allow Tool의 작업은 알맞은 기본 역할에 자동으로 들어갑니다.

<!-- l10n:detail -->
Haul+는 기본 작업(Basics)에 포함되고, 나머지 작업은 해당 작업을 이미 다루는 역할에 포함됩니다. 마무리(Finish Off) 같은 일회성 작업 때문에 기본 작업이나 사냥꾼이 근접 역할로 취급되지는 않습니다. 이미 Allow Tool을 사용 중인 저장 파일에 WorkRoles를 추가해도, Haul+는 기존에 지정받았던 정착민에게 그대로 유지됩니다.

---
title: 화면 크기
---
WorkRoles는 게임 화면 1536x864 이상을 기준으로 합니다. 게임 화면은 해상도를 UI 배율로 나눈 값이므로 1920x1080에 1.25 배율이면 정확히 맞습니다.

작은 화면에서도 창이 화면을 채워 작동하지만 일부 이름이 줄고 스크롤이 늘어납니다. 게임 옵션에서 UI 배율을 낮추면 공간이 늘어납니다.

선택한 정착민 패널은 기본 12개 기술을 두 열로 표시합니다. 추가 기술 모드가 있으면 세 번째 열을 만들고 추천 패널을 좁힙니다. 18개를 넘으면 행을 추가합니다.

추천 역할이 다 안 보이면 패널 안에서 스크롤하세요. 실행 버튼은 계속 보입니다.

Allow Tool 的工作會自動歸入相符的預設職責。

<!-- l10n:detail -->
Haul+ 會加入「基本」職責,其他工作則加入已涵蓋其工作內容的職責。像「補刀」這類一次性工作,不會使「基本」或「獵人」被視為近戰職責。將 WorkRoles 加入已使用 Allow Tool 的存檔時,原本擁有 Haul+ 的殖民者會繼續保有它。
